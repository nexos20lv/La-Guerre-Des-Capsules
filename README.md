## 🎮 Présentation du Jeu

**La Guerre Des Capsules** est un jeu indépendant axé sur l'action et le combat d'arène. Incarnez une capsule personnalisable et affrontez des vagues d'ennemis ou d'autres joueurs dans des niveaux remplis de pièges, de bonus et de physiques dynamiques.

---

## ✨ Caractéristiques

- 💥 **Combats Arènes Dynamiques :** Mouvements fluides, moteur physique réaliste et effets visuels explosifs.
- 🎨 **Direction Artistique Unique :** Un univers coloré et captivant construit sur le moteur Godot 4.
- 🚀 **Écosystème Dédié :**
  - **[La-Guerre-Des-Capsules-Launcher](https://github.com/nexos20lv/La-Guerre-Des-Capsules-Launcher)** : Lanceur officiel pour les mises à jour automatiques du jeu.
  - **[La-Guerre-Des-Capsules-DL](https://github.com/nexos20lv/La-Guerre-Des-Capsules-DL)** : Serveur d'hébergement des assets et patchs de mise à jour.

---

## 🛠️ Compilation & Lancement depuis les Sources

### Prérequis
- **Godot Engine 4.x** (Version stable recommandée)

### Étapes
1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/nexos20lv/La-Guerre-Des-Capsules.git
   ```
2. Ouvrez **Godot Engine** et cliquez sur **Importer**.
3. Sélectionnez le fichier `project.godot` situé à la racine du projet.
4. Appuyez sur `F5` dans l'éditeur Godot pour lancer le jeu !
